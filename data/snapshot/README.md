# 数据快照说明

本目录存放**从麦当劳中国 MCP 实际调用得到**的原始数据快照，供前端演示与离线核对使用。
文件名与来源一一对应，不含任何人工编造或估算值。

| 文件 | 来源 Tool | 采集时间 | 规模 | 说明 |
|---|---|---|---|---|
| `raw-menu.json` | `query-meals` | 2026-10-21 | 14 分类 / 111 餐品 | 门店 1990102（南京仙林金鹰餐厅），到店自取（orderType=1, beType=1） |
| `raw-nutrition.json` | `list-nutrition-foods` | 2026-10-21 | 160 行 | 接口返回的紧凑表格文本原文 |
| `real-details.json` | `query-meal-detail` | 2026-10-21 | 111 条 | 逐品项详情，用于补全菜名 |
| `price-map.json` | `calculate-price` | 2026-10-21 | 111 条 | 逐项计价，单位「分」，换算后与菜单挂牌价一致 |
| `real-joined-all.json` | 上述四者关联 | 2026-10-21 | 111 行 | 编码 + 菜名 + 挂牌价 + 热量 + 蛋白/脂肪/碳水/钠 的汇总表 |

## 复现方式

```bash
set MCD_MCP_TOKEN=<your-token>
cd scripts
python mcp_smoke.py            # 六段链路冒烟，验证 MCP 可用
python check_snapshot.py       # 快照 vs 实时数据三维比对（在售/价格/热量）
```

## 一致性结论（2026-10-21 14:53 校验）

- 111 项餐品**全部仍在售**，无下架；
- 营养数据零变动；
- 17 项价格差异**全部为 `9900` 开头的套餐码**（菜单挂牌价是活动价，与单品原价口径不同）；
- 前端页面展示的 22 项菜品，与实时挂牌价**逐项一致**。

注意：MCP 返回的是门店实时数据，价格与在售状态会随档期变化。演示前建议先跑一次 `check_snapshot.py`。
